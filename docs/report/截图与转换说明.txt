2) 文件 → 打开 → 浏览到上面那个 .xml（文件类型要选「XML 格式」或直接输入文件名）
3) 打开后应该是 5 行任务：
   Catalog management（2 天）、Reader management（1 天）、Borrowing and returns（2 天）、
   Catalog search（1 天）、Overdue reminders（2 天）
   前置关系：3 的 1,2；4 的 1；Overdue reminders 的 3,4
   ※ 如果打开后发现「工期」列显示 0 天、前置任务为空，说明这台机器的 Project
     没有把 XML 里的工期解析进来（我们在这台机器上做自动化导入时没能验证成功）。
     这时不用纠结，直接在 Project 里手动补一遍即可，30 秒的事：
       - 双击每行「工期」列，依次填 2 天、1 天、2 天、1 天、2 天
       - 双击每行「前置任务」列：第 3 行填 1,2；第 4 行填 1；第 5 行填 3,4
       - 开始日期改成 2026-11-16
     填完后关键路径会自动变成 T1 → T3 → 逾期提醒，与报告表 4-1、表 4-2 完全一致。

五、常见问题
----------------------------------------------------------------
Q: 打开 Word 提示「此文档包含的域可能引用其他文件」
A: 选「是」即可，这只是目录域的正常提示。

Q: 目录更新后页码不对
A: 截图都已经插好了；如果你又改了正文，把目录整体更新一次，页码就稳定了。

Q: 截图看不清
A: 浏览器按 Ctrl 和 + 把页面放大到 110%～125% 再截，插入 Word 后不要缩得太小，
   建议每张图在文档里保持 14～15 cm 宽。

Q: 平台跑起来是空白页
A: 确认是在 code 目录下用 .\.venv\Scripts\python.exe -m app.serve 启动的，
   并且浏览器访问的是 http://127.0.0.1:8000（不是 8077）。
